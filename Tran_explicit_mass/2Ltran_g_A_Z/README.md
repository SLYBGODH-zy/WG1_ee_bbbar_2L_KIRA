# 2Ltran_g_A_Z

## Note / 说明

This directory does not contain `kira_run` configurations because all amplitudes for the A-Z interference contribution in the transverse part are **exactly zero**.

该目录不包含 `kira_run` 配置文件，因为横向部分的 A-Z 干涉贡献的所有振幅**恰好为零**。

No IBP reduction is needed for this contribution.
